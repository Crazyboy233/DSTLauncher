# 世界选择器（World Selector）

HUD 右下角点「世界」，弹出一个列表，自己选一个已连接的世界过去。**任意玩家可用，不需要管理员权限。**

专为多世界（多分片）服务器设计：地表、洞穴、自定义世界之间自由穿梭。

## 功能

- 列表来自引擎的 `Shard_GetConnectedShards()`：**只显示当前真正连着的世界**，没起来的世界不会出现（不是灰掉，是直接不在列表里）。
- 点一行 → 服务端校验 → 迁移由引擎完成，身上的物品一起带走。
- 同一玩家两次迁移之间有 30 秒冷却；迁移进行中按钮锁定；被拒绝的原因显示在面板底部。
- `irreplaceable` 物品和带宠物的物品会被留在原地（与原版走洞穴入口的行为一致）。

## 安装

这是一个**双端 mod**（`all_clients_require_mod = true`），服务端和客户端都要装。

**服务器端**：在 `modoverrides.lua` 里启用（每个分片都要有，因为迁移逻辑是各分片独立注册的）：

```lua
return {
  ["workshop-3824040537"] = { enabled = true },
}
```

用 dst-windows 面板的话，模组页勾选「世界选择器」即可，它会自动写全部分片。

**客户端**：订阅本工坊物品即可。因为 `all_clients_require_mod = true`，加入服务器时客户端会自动下载并启用，无需手动进模组列表打开。

## 已知边界

- **落点是目标世界的默认出生点**。目标世界没有 id 对应的 `worldmigrator` 门时无法指定具体落点。
- **不检查目标世界人数上限**，也没有二次确认。
- 只在「多世界（shard_enabled）」服务器上有意义；单世界服务器列表会是空的。

## 排障

- 列表为空：目标分片还没起来或没连上主世界（`Shard_GetConnectedShards` 里没有它）。
- 控制台 `c_debugshards()` 可查看已连接分片与传送门绑定；`c_migrateto(worldId, portalId)` 可手动迁移。
