## 世界选择器 mod 方案调研（仅设计，未写代码）

用户想在 DSTLauncher 这套面板之上配一个「世界选择器」mod（玩家在多个分片间选择进哪个世界）。
官方脚本副本在 `/Users/chihiro/AgeOfDecay/data/scripts`（4030 个 lua，完整）。

### 已核实的引擎能力（关键行号）
- `consolecommands.lua:1367` `c_migrateto(worldId, portalId)` —— 原版就有跨分片迁移命令，玩家取 `ConsoleCommandPlayer()`（:2，兜底 `AllPlayers[1]`）。
- `components/playerspawner.lua:156` `OnPlayerDespawnAndMigrate`（监听 `ms_playerdespawnandmigrate`）→ `PlayerRemove`（:96）→ `TheShard:StartMigration(userid, worldid)`（:109）。玩家实体经 session 序列化带到目标分片。
- `componentutil.lua:1069` `GetMigrationPortalLocation`：portalid 命中目标世界的 worldmigrator 门 → 落在门边；否则用 dest_x/y/z；都没有 → `playerspawner:GetAnySpawnPoint()`（默认出生点）。
- `shardnetworking.lua:16` `Shard_IsWorldAvailable`、`:145` `Shard_GetConnectedShards()` → `{ [world_id] = { ready, tags, world, shard_name } }`。仅服务端有数据。
- `constants.lua:2481` `SHARDID = { INVALID="0", MASTER="1" }` —— **分片 id 是字符串**（`networkclientrpc.lua:1779` 也用 tostring 比较）。
- mod RPC：`modutil.lua:857/892/910`、`networkclientrpc.lua:1834/2001`（AddModRPCHandler / SendModRPCToClient / GetClientModRPC）。
- 面板：`internal/room/generate.go:78` 写 `server.ini [SHARD] id = GameID`，主世界 id=1、洞穴 2；分片名 = 目录名 = `shard_name`。

### 方案骨架
1. 服务端 mod 收客户端 RPC `RequestTravel(worldid)` → 校验（admin/冷却/可用）→ push `ms_playerdespawnandmigrate`。
2. 客户端 mod 存列表、开 HUD 列表；数据由服务端 `Shard_GetConnectedShards()` 经 RPC 下发。
3. 展示名等元数据由面板写进**每个分片的 modoverrides.lua**（同一份完整世界表 JSON 塞进一个 string 配置项），各分片自读，免跨分片同步。
4. 面板不能替玩家迁移（stdin 控制台 `c_migrateto` 只能落到 `AllPlayers[1]`），玩家级操作必须走 mod。

### 待用户拍板
入口形态（HUD 按钮 / 热键 / 出生弹窗 / 建筑）、权限（所有人 / 仅 admin）、是否要面板联动世界展示名。

## 已实现 v0.1（用户拍板：HUD 常驻按钮 + 内置名称映射，任意玩家可用）

新增文件：
- `mods/worldselector/modinfo.lua`、`modmain.lua`、`README.md`
- `tools/worldselector/test_mod.lua`（stub 验证，23 项全过；`lua tools/worldselector/test_mod.lua`）

实现要点：
- 双端 mod：客户端只画 HUD 按钮 + 浮层列表，点行发 `Travel` RPC；服务端校验后 push
  `ms_playerdespawnandmigrate`。**RPC 层不校验 admin**（`networkclientrpc.lua:1897` HandleModRPC
  只检查 sender 是玩家实体 + 每 tick 限流），所以「任意玩家自己选世界」天然成立。
- 列表 payload 用字符串 `id\t名字\t类型\n` 编码，不用 RPC 传 table。
- 服务端校验：自己世界 / `Shard_IsWorldAvailable` / `_despawning` / 30s 冷却；迁移前跑
  `DropEverythingByFilter`（irreplaceable + 带宠物的物品留在原地，对齐 worldmigrator 口径）。
- UI 用 `images/global.xml` 的 `square.tex` 靠 SetTint 上色，零美术资源；面板挂
  `ThePlayer.HUD.root`，按钮挂 `controls.bottomright_root`（位置 `{-138,-50}`，待实测微调）。

**关键坑（已核实源码）**：本地 mod 不能设 `all_clients_require_mod = true`。
客户端缺该 mod 时走 `QueueDownloadTempMod`，本地 mod 无工坊 id → 报
`SERVER_MODS_NOT_ON_WORKSHOP`（`networking.lua:467-484`），**没装 mod 的玩家直接进不来**。
所以当前为 `false`：客户端必须自己装并手动启用；上架创意工坊后才改 `true` 实现无感下发。
